LIBRARYDESK — FRONTEND ONLY

Included pages:
- index.html       Dashboard
- login.html       Demo login screen
- books.html       Books list, search, edit, delete
- book-form.html   Add/edit a book
- members.html     Members list, edit, delete
- member-form.html Add/edit a member
- loans.html       Loans summary and demo loan actions
- css/style.css    Responsive styling
- js/app.js        Frontend interactions and browser storage

HOW TO OPEN IN VS CODE
1. Extract the ZIP folder.
2. In VS Code choose File > Open Folder and select library_management_frontend.
3. Open index.html.
4. If you have the Live Server extension, right-click index.html and choose "Open with Live Server".
   Or open index.html directly in a browser.

IMPORTANT
This is a static HTML/CSS/JavaScript frontend demo. It stores demo data in the current browser's localStorage.
The login is only a visual/demo flow; it is NOT secure authentication. It does not connect to Laravel, MySQL, or a server.
For your PDF's full project, Laravel backend routes/controllers, migrations, database configuration, and real authentication
must be connected separately. Bootstrap and Google Fonts use internet CDNs.
